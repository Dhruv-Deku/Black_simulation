# Black_simulation
A real-time simulator of a **rotating (Kerr) black hole**, written in C++20 and OpenGL 4.6. Every pixel is ray traced through curved spacetime on the GPU, and everything in the scene is lensed, Doppler-shifted and redshifted by the same physics: stars, planets, pulsars, torn-apart stars, glowing gas, jets, even the orbit lines you draw.
